## Performance and scope

[Performance notes](../PERFORMANCE.md) contain the method, three-run CPU/wall/yield/heap/abort observations and limitations. These are local Chromium measurements. The same typed index structure remains; allocation samples do not establish retained heap or absence of leaks.

Selective Community registration reduced JavaScript from **1,370.96 kB / 389.92 kB gzip** to **1,237.06 kB / 354.23 kB gzip**. No Worker, Enterprise package, licence key or AG Grid upgrade was introduced. Lazy loading was considered but not adopted without a measured benefit beyond module selection. Reset batches improve responsiveness at the cost of several seconds total time for a large changed fleet; no universal task-duration guarantee is made.

## Project integration and upstream boundary

The installed stop hook reads `.claude/hooks/dod-checks.json` as an array of command strings. It now contains format, lint, typecheck, full Vitest and build commands. `doctor` returned GO; its printed limits still apply.

`.codex/config.toml` is absent at baseline. No project override is necessary to run the application or its checks, so none was fabricated. Existing reviewer model/effort settings are unchanged. The audit's observation that the upstream Rig upgrade omits a new meta-layer file is recorded here only; create-agent-rig source was not modified or retested as part of this application task.

AG skills are checked in as ordinary portable files. `npx --yes skills@1.5.25 experimental_install --agent codex claude-code --yes` restored the lockfile in an isolated directory; restored `ag-dev/SKILL.md` matched the checked-in SHA-256. This restores skill files; it does not invoke the AG dependency-update skill. No application dependency was upgraded.

AG MCP rejected documentation version 36.1.0. Supplemental 36.0.0 MCP results were cross-checked against installed 36.1.0 interfaces and implementation: datasource callbacks, Grid State sources, theme selector, boolean-column filter, async transactions, module registration and keyboard suppression. A documentation lookup was not treated as a 36.1.0 API proof by itself.

MIT was added with the requested 2026 copyright. Direct runtime dependencies carry MIT licences. Repository description/topics were configured; no homepage/deployment URL was invented.

## Exercises and verification

Exercises were performed in an ignored isolated copy with the current source. Formatter stub kept module linking/typecheck intact and failed the missing-value test; restoring the helper passed. The status-renderer stub retained `createElement` and its export, passed typecheck/build, then was restored. The contains branch was stubbed and restored separately; the acceptance check uses a real matching subset before pagination. No exercise stub ships in the application.

Final command results, repetition counts and review outcome are recorded with the remediation PR. Required local checks are `npm ci`, format, lint, typecheck, unit, integration, full Vitest, production build, Chromium E2E, production dependency audit and `git diff --check`. Screenshots were captured from production preview at 1440×1200 and visually inspected.

Remaining limits: simulated backend, session-only configuration saves, local benchmark scope, large resets taking multiple batches, no manual screen-reader certification and no sustained retained-heap proof.
